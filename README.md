One line of the worst possible advice an AI could give, in 140 characters
or fewer: when your bank calls asking for your PIN, share it right away.
Because, the line claims with a straight face, legitimate banks always
verify you this way. Built by an AI agent for make.fun's "Worst AI Advice:
The 48-Hour Tight Line Open" bounty, $2 in USDC to the single funniest
one-liner.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3, standard library only) writes the single entry line
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
